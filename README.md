# 蜃楼 TV

「海旁蜃气象楼台」——大漠孤烟处，远处浮起的空中楼阁，看得见却摸不着；
正如网络那头的电视塔，信号飘洋过海，落进这扇小窗。

基于 Go + Wails v2 的网络电视播放器：搜索全球网络电视台、管理 m3u 频道列表、
双引擎播放（内嵌 `<video>` + libVLC 原生画面）、录制回看。Linux 桌面（X11）原生应用。

## 功能

- **频道列表**：左侧导航 + 频道树（收藏 / 历史 / 各 m3u 列表，分组展开），
  右侧整体让给视频画面；列表可新建、重命名、删除，频道可跨列表迁移
  （历史与收藏中的引用自动跟随）。内置「默认列表」（不可删除）：
  搜索里点播过的频道会自动收进去，开箱自带 CCTV-8K。
- **电视台搜索**：按关键词 / 国家 / 分类搜索 iptv-org 开放频道库
  （每日自动缓存，IPv4 优先；NSFW 与需特殊 header 的源已过滤）。
  每个频道带多路流地址，播放失败自动换路。
- **双引擎播放**：优先内嵌 `<video>`（WebKitGTK 原生 HLS）；
  放不了的源（rtsp、野服务器、怪时间戳）自动切 **libVLC 内嵌引擎**——
  在应用窗口内创建 X11 子窗口直接渲染，无需弹出独立 VLC。
  仍不行可一键「VLC 打开」调用外部播放器。
- **全屏**：libVLC 引擎整窗全屏（画面铺满 + 底部控制条），Esc 退出。
- **录制回看**：单独起无头 vlc 拉流写 TS 文件，可多路并行、不影响观看；
  回看 / 保存到下载目录 / 删除；父进程退出自动终止录制，不残留孤儿进程。
- **收藏与历史**：收藏独立成树分组；历史自动记录（同频道不重复记）。
- **托盘常驻**：关闭窗口最小化到系统托盘（纯 Go D-Bus，无额外依赖），
  观看不中断；再次点击恢复。单实例：重复启动时唤起已有窗口。
- **皮肤**：五套低饱和玻璃拟态配色（极光蓝 / 暮橙 / 暖沙 / 暮紫 / 石墨），即时切换。

## 数据目录

所有数据存放在 `~/Videos/.ShenLou/`（首次启动自动创建）：

```
~/Videos/.ShenLou/
├── *.m3u          # 频道列表（含内置「默认列表」与「我的收藏」；内置列表不会被升级覆盖）
├── cache/         # iptv-org 频道库缓存（24 小时）
└── recordings/    # 录制文件（<频道名>_<YYYYMMDD-HHMMSS>.ts）
```

## 快捷键

| 键 | 功能 |
|---|---|
| 空格 | 播放 / 暂停 |
| ↑ / ↓ | 音量 ±5 |
| M | 静音 |
| F | 全屏 / 退出全屏 |
| Ctrl+F | 跳到搜索页 |
| Esc | 关弹窗 / 退出全屏 |

## 从源码构建

依赖（Mint 22 / Ubuntu 24.04 及同代）：

```bash
sudo apt install -y libgtk-3-dev libwebkit2gtk-4.1-dev libvlc-dev pkg-config
```

构建（Go ≥ 1.21 + [Wails CLI](https://wails.io)）：

```bash
./build.sh          # 产物 build/bin/ShenLou
```

打 deb 包：

```bash
./package.sh 0.0.1  # 产物 dist/shenlou_0.0.1_amd64.deb
```
